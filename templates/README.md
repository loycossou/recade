# Templates

Starting points for the documents Recade writes. Placeholders look like `{{key}}`; `fillTemplate` replaces them.

- `D1.md`: Functional Specifications, 15 sections and two annexes.
- `D2.md`: Technical Architecture, 14 sections.
- `D3.md`: Security Requirements, sections 0 to 10.
- `STACK.md`: the stack decision, with the weighted matrix and the harness technical sheet.
- `PLAN.md`: the delivery plan, one H2 per workbook sheet.
- `BIBLE.md`: the rules agents apply, sections 0 to 17.
- `slice.md`: one slice sheet, with `touches:` and `format:` in its header.
- `DEC.md`: one decision file, two options and a recommendation.
- `BLOCKERS.md`: the append-only log of blocking questions.
- `provisionals.md`: the open and closed provisional values.
- `retro.md`: the retrospective of one increment.
- `questionnaire.md`: the intake questions of phase 0.
- `doctrine.md`: one team member's doctrine.
