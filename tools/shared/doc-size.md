The dispatcher gives the budget of your document in words, code blocks excluded. Write for a busy client: one idea once, tables only for real tabular data, other documents cited by ID with their gist instead of restated. Cite a decision, a rule or an ID once, where it applies, not again in every section that touches it. Before you report, run `recade docs size '<document>' --project '<project folder>'`: over budget, cut. Never summarise the cut, and never move the words into another document.
