# Fernhill Lending, art directions

## Boards

- `ledger-paper.html`: the desk as a paper ledger. Warm off-white page, ink-blue text, one rust accent for late tools. Costs a day to build: two fonts, no images.
- `shelf-labels.html`: the desk as the shelf labels of the library. Large type, coloured tags for the state of a tool. Costs two days: a tag set to draw.

The logo is a text wordmark and is PROVISIONAL (PRV-02).

## Direction chosen

`ledger-paper`, chosen by the owner. The tokens are in `design/tokens.json` and the render theme in `design/theme.json`. Body text is 16 pixels or more. The rust accent on the off-white page has a contrast ratio of 5.1.
